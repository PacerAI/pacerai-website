Add Pacer AI - Demo in Claude 6 steps · 2 min

What happens after you click the button. It opens claude.ai in your browser; in the Claude desktop app, add it by hand (step 1).

  1. 1

    Click Add Pacer AI - Demo to Claude

    Signed in to claude.ai in your browser? The button opens Claude’s Add custom connector dialog with the name and server URL already filled in.

    Add Pacer AI - Demo to Claude

    Not signed in to Claude? It asks you to sign in first, then opens the dialog with everything filled in.

    On a Claude Team or Enterprise plan, only an Owner can add a custom connector. If Claude says you can’t, ask your Owner, use a personal Claude account, or book a walkthrough.

    Dialog opened empty, or using the desktop app? Add it by hand.

    Click + in the prompt box → Connectors → Add connector → Add custom connector, then paste these two values.

    Name

    Pacer AI - Demo

    MCP server URL

    https://pacerai-demo-mcp.azurewebsites.net/mcp

    Click a box to select it, then copy.

  2. 2

    Click Continue, then Add

    Check the name and URL and click Continue. Claude detects Sign in now and Register automatically. Leave both as they are and click Add.

  3. 3

    Connect

    Claude opens the Pacer AI sign-in page in a new window.

    No sign-in page? Open Settings → Connectors → Pacer AI - Demo and click Connect.

  4. 4

    Sign in with your work email

    On the Pacer AI sign-in page, enter your work email, pass the quick bot check and click Start the demo. There is no password.

  5. 5

    Allow the tools to run

    In Settings → Connectors → Pacer AI - Demo, open the Interactive tools menu under Tool permissions and choose Always allow. Claude then draws each chart without stopping to ask.

  6. 6

    Ask Are we on pace?

    Start a new chat and ask Are we on pace? The month, quarter and year pacing charts render right in the chat.
