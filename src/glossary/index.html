Questions

What is an ARR waterfall?

An ARR waterfall is the single-period bridge from beginning ARR to ending ARR. The definition used on this site is on the ARR waterfall glossary page and in the longer article, What Is an ARR Waterfall?

What is an ARR snowball?

An ARR snowball follows recurring revenue across periods so you can see what drove the change. The article What Is an ARR Snowball? is the long definition. A separate article compares the snowball with the waterfall.

What is cRPO?

cRPO is current remaining performance obligations. The operator's guide is What is cRPO? on this site. This glossary does not restate the guide.
