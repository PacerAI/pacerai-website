What is the AI engineering ladder?

The ladder is the stack that takes a company from the system of record to a front end a sales leader will use. The MCP — the tools people usually mean when they say “build an MCP” — sits at rung five of seven. Starting there leaves the data model, the pipeline and the system knowledge unbuilt.

Costs on the one-pager come from a companion model that uses the Robert Half 2026 Salary Guide, BLS OEWS (May 2025) and Glassdoor, then applies a 1.3× load factor (Hadzima, MIT). Run staffing is taken at 50% of the build. Limits are from the Salesforce, HubSpot, Oracle NetSuite and Sage Intacct developer docs. Security sources are the MCP specification, OWASP GenAI, Invariant Labs, JFrog and Knostic. The one-pager checked those web sources on October 29, 2026.

What sits beside every rung?

The one-pager puts a governance rail alongside the ladder: seven rows an in-house plan rarely budgets. Together they are $54K to stand up, $181K a year to keep, and 1.75 FTE-fractions.

  • Access permissions. OAuth 2.1 with PKCE, resource indicators, and protected-resource metadata — the MCP spec as of the 2026-07-28 revision. The one-pager cites 1,862 MCP servers found online with no auth at all.
  • Role-based access (RBAC). Per-user identity against an approved list; removal takes effect on the next request, not the next login. One shared password is not RBAC.
  • Data privacy policy and retention. What the agent stores and for how long; no prospect data in version history; a DPA with the model vendor; an answer for the security questionnaire.
  • Prompt-attack defense. OWASP LLM01. A booby-trapped CRM note or tool description can make the agent leak data. The one-pager points to documented cases against WhatsApp and GitHub MCP servers in 2025.
  • Guardrails. Read and write allow-lists on separate keys; nothing that can send email on either; preview, confirm, and read back every write. The CRM API has no delete (OWASP LLM06).
  • Audit, logging and monitoring. Every write logged with the values it replaced; sessions never used as credentials; secrets never in code.
  • Vendor and spec change management. The spec moved twice in a year; mcp-remote shipped a CVSS 9.6 flaw in July 2025. Someone has to own the upgrades.

What does the in-house path cost?

Put the 14 rows together — the seven rungs and the seven governance rows — and the one-pager’s totals are:

  • $351K to build, over 17 months elapsed.
  • $664K a year to run, across 3.4 FTE in six roles.
  • $1.0M in the first operating year. That last figure is a buyer’s own estimate, given unprompted, as recorded in conversations in October 2026.
