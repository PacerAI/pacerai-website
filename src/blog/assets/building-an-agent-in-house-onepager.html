The governance rail — alongside every rung

Seven rows an in-house plan rarely budgets. Together: $54K to stand up, $181K/yr to keep, 1.75 FTE-fractions.

Access permissions

OAuth 2.1 with PKCE, resource indicators, protected-resource metadata — the current MCP spec (rev. 2026-07-28). 1,862 MCP servers were found online with no auth at all.

Role-based access (RBAC)

Per-user identity against an approved list; removal takes effect on the next request, not the next login. One shared password is not RBAC.

Data privacy policy & retention

What the agent stores and for how long; no prospect data in version history; a DPA with the model vendor; an answer for the security questionnaire.

Prompt-attack defense

OWASP LLM01. A booby-trapped CRM note or tool description can make the agent leak data — documented against WhatsApp and GitHub MCP servers in 2025.

Guardrails

Read and write allow-lists on separate keys; nothing that can send email on either; preview, confirm, read back every write. The CRM API has no delete (OWASP LLM06).

Audit, logging & monitoring

Every write logged with the values it replaced; sessions never used as credentials; secrets never in code.

Vendor & spec change management

The spec moved twice in a year; mcp-remote shipped a CVSS 9.6 flaw in July 2025. Someone has to own the upgrades.
