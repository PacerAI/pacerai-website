# Brand Compliance Rules

1. **Colors from foundation.** Navy (#1B365D), teal (#2B8C96), white (#FFFFFF), slate backgrounds (#F8FAFC, #F1F5F9). Full palette in `foundation/brand/colors.yml`.

2. **Typography from foundation.** Cormorant Garamond for headings, DM Sans for body. Defined in `foundation/brand/typography.yml`.

3. **Design system from foundation.** Logo usage, button styles, layout rules in `foundation/brand/design-system.yml`. Don't invent new component patterns without checking the design system first.

4. **CTA language from foundation.** Approved and forbidden CTA copy in `foundation/products/cta-language.yml`. Never use forbidden CTAs even if they seem effective.

5. **No emojis.** Not in page content, not in meta descriptions, not in CTA buttons. Will's audience reads CIMs and board decks for a living.
